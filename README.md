# TouhouLittleMaid-BetterGap
[车万女仆](https://www.mcmod.cn/class/1796.html)
(Touhou Little Maid)附属模组，基于原版隙间饰品进行全面增强升级

## 📋 前置依赖
必须安装 **车万女仆(Touhou Little Maid)**，本模组仅为附属扩展，无法独立运行。

## 📖 模组简介
原版隙间饰品功能强大，但存在不少使用痛点：只能绑定单个原版箱子、受距离维度限制，修改配置必须把饰品从女仆饰品栏取下、设置完再装回，操作繁琐。

本附属模组提供**全新的增强版隙间**，保留原版隙间的核心逻辑（女仆槽位配置、物品黑白名单），在此基础上增加大量实用新特性，同时新增**隙间终端**物品，无需拆卸饰品就可以实时修改隙间全部参数。

## ✨ 核心功能
### 🌀 增强隙间（新饰品）
- 🖥️ 全新定制GUI配置界面，操作体验大幅优化
- 📦 支持绑定**多个容器**，兼容模组添加的箱子容器，不再局限原版箱子
- 📏 可自定义隙间工作检测距离，摆脱原版固定范围限制
- 🌌 **跨维度生效**，不受维度阻隔
- 🔢 可设置每次物品传输的拿取数量，精细控制流转速率
- 🛒 **玩家自动补货功能**：自动从绑定容器取出物品补给玩家
- ⚫⚪ 完整保留原版能力：女仆槽位配置、物品黑名单/白名单筛选

### 📟 隙间终端（新增道具）
> 解决原版痛点：不用反复把隙间从女仆饰品栏取下再装回
- 手持隙间终端，即可**实时修改对应增强隙间的全部配置**
- 简单快捷，无需操作女仆饰品栏，生存、服务器环境都很方便

## 📌 和原版隙间区别
1. 原版隙间仅支持绑定单个原版箱子；增强隙间支持多容器、模组容器
2. 原版受距离、维度限制；增强隙间支持自定义距离、跨维度工作
3. 原版修改配置需要取下饰品；搭配隙间终端可实时配置
4. 新增单次拿取数量调节、玩家自动补货能力
5. 保留黑白名单、女仆槽位过滤等原版全部筛选逻辑

## 🛠️ 使用说明
1. 安装前置【车万女仆】与本附属模组
2. 获取增强隙间饰品，放入女仆饰品栏生效
3. 可直接打开隙间GUI配置各项参数；也可使用**隙间终端**远程调整
4. 绑定多个容器，设置传输距离、单次拿取数量，开启自动补货
5. 黑白名单、女仆槽位过滤在新GUI内依旧可以正常配置
